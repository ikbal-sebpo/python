Bulk create new joiners

Create a batch of new employees from a spreadsheet — Employee ID and login Email are auto-assigned when left blank, and each new employee gets a one-time password so they can sign in and fill in their own profile on day one.

Back to users

1. Download a template

Excel template Department/Designation/Team/Job Location/Work Location/Employment Type/Resource Status/Billing Status/Reason are dropdowns sourced from live reference data — a hidden "Existing employees" sheet lists Employee ID + Name for filling in Reports To.

2. File format

One row per new joiner. Only Full Name and Department are required — everything else can be left blank and filled in on the profile later.

  • Employee ID — blank auto-assigns the next number after the current highest.
  • Email — blank auto-generates a unique first.last@sebpo.com-style address (Data Solutions uses initials); fill it in yourself to override.
  • A random password is generated for every new employee — it isn't a template column, it only appears once, on the results workbook after you apply the upload. There's no separate "change your password on first login" step yet, so treat it as something the new joiner should change themselves once they're in.
  • Gross Monthly Salary needs an Effective From date alongside it — leave both blank to skip starting pay for now (Finance can add it later via the existing gross-salary upload).
  • Grade, Cost Center, and Sub Project aren't part of this sheet — set those on the profile once decided.
