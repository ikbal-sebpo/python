Import salary history

Restricted to Payroll Admins. One-time load of an employee's full gross-salary history — every past figure with its dates, plus the current one. Only for employees with no salary records in Orbis yet; anyone who already has records is skipped. Day-to-day changes go through Upload gross salary.

1. Download a template

Excel template One line per employee without salary records (ID, name and joining date for reference). Add one row per historical salary beneath each — the Employee ID repeats on every row.

2. File format

Several rows per employee, five columns, header on row 1:

Employee IDGross monthly salaryEffective fromEffective toReason
104331462009-01-012009-12-31
104368292010-01-012010-12-31Annual increment
1041459172026-01-01blank
  • Rows for one employee must form an unbroken chain: each Effective to is the day before the next row's Effective from. A gap or overlap rejects that employee's whole history.
  • Exactly one row per employee has a blank Effective to — the current salary.
  • A first row that starts before the joining date (HR's calendar-year sheets usually do) is clamped to the joining date and reported as a warning, not an error.
  • Reason is optional: blank means New hire for the oldest row and Annual increment for later ones. Accepted values: {% for value, label in reason_choices %}{{ label }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • Past rows are stored as closed-out history (Superseded) and the last row as the current Approved salary, so payroll prices every historical period at the rate actually in force.
