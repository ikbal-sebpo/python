TDS by challan (per employee){% if tax_year %} · {{ tax_year.code }}{% endif %}

Restricted to Payroll Admins. For every treasury deposit, which employees' tax it carried and how much of each. Record the deposit first under Tax challans, then upload this sheet — every month, for a pre-Orbis month and an Orbis payroll run alike. The tax certificate's challan table is a read of these rows. Re-uploading an employee / challan pair overwrites its amount — these are facts about a deposit that already happened, not a ledger.

1. Download a template

Excel template Prefilled: one row per employee per payroll month that has a challan recorded, amount = that month's TDS. The challan number is filled in when the month has exactly one challan; otherwise fill it in yourself.

  • One row per employee per challan. Challan No must already be in Orbis for this tax year; Amount is the taka of that employee's tax inside that deposit (whole taka; must be above zero).
  • Errors (unknown employee or challan, zero amount, the same pair twice) abort the file. Everything else is a warning: allocations not adding up to the challan's total, not equalling an employee's TDS for the month, employees with TDS in no challan yet, or one employee split across two challans of the same month (Finance's rule is exactly one).
  • A second tab, Challans, lists the year's challans for reference and is ignored on upload. CSV with the first tab's columns works too.
