Upload gross salary

Restricted to Finance. Sets each employee's current gross monthly salary.

1. Download a template

Excel template Prefilled with every active employee's ID, name and current gross salary for reference, plus a dropdown on the Reason column. Delete the rows you don't need to touch this cycle before uploading — an unedited row fails to parse.

2. File format

One row per employee, four columns, header on row 1:

Employee IDGross monthly salaryEffective fromReason
1042850002026-03-01Annual increment
  • Effective from is per employee — use the date their current gross salary actually took effect, not the upload date. Payroll runs pick a salary by this date, so getting it right matters for any period run or re-run before today.
  • Reason accepts either the code or the label below, case-insensitively: {% for value, label in reason_choices %}{{ label }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • Re-uploading the same employee supersedes their current gross salary — the earlier figure is kept as a closed-out history row, not overwritten.
  • There is no approval gate — your upload is final.
