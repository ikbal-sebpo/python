How it works

  • Wide template: each row is one employee; each date occupies two columns (Location and Shift). Headers on rows 1 and 2; data from row 3 onward.
  • Flat template: each row is one employee/date with Date, EmployeeID, User Name, Location, and Shift Status.
  • Existing (employee, date) shifts will be overwritten. Days you leave blank are untouched. A day already carrying approved leave (CL/SL/AL/…) is protected by default — check Override approved leave below to force it anyway.
  • Empty Location cells fall back to each employee's default office at display time.
  • You can only upload rows for employees in your managed scope; others are rejected per-row.
